    How the cache sees it

    Prompt caching stores the processed form of the start of your prompt. On the next call it matches your prompt against the stored copy from the top and stops at the first difference. Everything above that line is a hit. Everything from the line down is paid for again, even if a later block never changed.

    So the order is the strategy. A timestamp near the top costs you the cache on all the tokens beneath it. This toy uses $3 per million fresh input tokens and $0.30 per million cached, and counts the first turn as all fresh.
