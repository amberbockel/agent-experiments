Each round, rewrite the description for one skill. The router below loads a skill when a request shares at least two words with its description, and the closest match wins. Get every request routed correctly.

      Three lines, each under a hundred characters, and an agent could pick the right tool every time. That is the whole trick behind skills: the description is the only part always loaded, so it is the only part the agent can judge you by. The full instructions in the body stay closed until the description earns them.

      Vague lines trigger on everything. Crowded lines trigger on lookalikes. The sharp ones name the verbs people actually use.

      Inspired by the wave of agent-skill and SKILL.md tooling, where a skill's frontmatter description decides when it loads. The router here is a deliberately simple word-overlap model, not a real LLM, so every decision is visible. Runs fully offline.
